# Password-Strength-Checker-in-Python


Overview
This Python script checks the strength of a password based on various criteria. It scores the password and provides feedback on its strength. The password is evaluated based on:

Presence of uppercase and lowercase letters.
Presence of numbers.
Presence of special characters.
Length of the password.
No duplicate characters.



Features
Checks Criteria: The script evaluates the password based on a set of rules:
Uppercase letters
Lowercase letters
Numbers
Special characters (symbols)
No duplicate characters
Length of the password


Score System: The password is given a score from 0 to 6, based on the number of criteria met.
